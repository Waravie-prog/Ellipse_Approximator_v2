# Подсистема аппроксимации морфологических объектов (ГА)

Инструмент для автоматизированного разделения слипшихся пор на бинарных масках микроструктур с использованием генетического алгоритма.

## 🛠 Технологический стек

- **Язык:** Python 3.8+
- **Библиотеки:** 
  - NumPy
  - scikit-image
  - Matplotlib

##  Описание

Проект реализует задачу многопараметрической оптимизации для аппроксимации сложных объектов набором геометрических примитивов (окружностей/эллипсов). 

**Основные особенности:**
- Использование генетического алгоритма для поиска оптимальных параметров
- Фитнес-функция на основе площади несовпадения и штрафных коэффициентов
- Автоматическое разделение слипшихся объектов
- Визуализация результатов аппроксимации
