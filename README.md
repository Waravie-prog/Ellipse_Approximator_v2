###Подсистема аппроксимации морфологических объектов (ГА)
###Инструмент для автоматизированного разделения слипшихся пор на бинарных масках микроструктур с использованием генетического алгоритма.
###🛠 Технологический стек
Язык: Python 3.8+
Библиотеки: NumPy, scikit-image, Matplotlib
🚀 Быстрый старт
###Установка зависимостей:
pip install -r requirements.txt
###Запуск:
python circle_approximator.py
###📌 Описание
Проект реализует задачу многопараметрической оптимизации для аппроксимации сложных объектов набором геометрических примитивов (окружностей/эллипсов). Используется фитнес-функция на основе площади несовпадения и штрафных коэффициентов.
